  1. Ouvre console.cloud.google.com et crée un projet.
  2. Dans « API et services », active Gmail API, Google Calendar API et Google Drive API.
  3. « Écran de consentement OAuth » : type Externe, puis ajoute ton adresse Gmail dans « Utilisateurs test ».
  4. « Identifiants » → Créer → « ID client OAuth » → type « Application Web ».
  5. Dans « Origines JavaScript autorisées », ajoute :
  6. Copie l'ID client ici, puis touche « Connecter Google ».

La connexion dure 1 heure, puis il suffit de toucher « Reconnecter ». Rien ne quitte ton appareil, sauf vers Google et le modèle choisi.
